Cоздан и настроен workflow для автоматического тестирования и публикации приложения в DockerHub. 
Для этого созданы два jobs:
1) первый проверяет код на наличие ошибок и запускать тесты;
2) второй при добавлении тегов автоматически публикует приложение в DockerHub.
